# Java Array Programs

This repository contains Java programs for learning and practicing
array concepts, searching, sorting, and problem-solving.

## Topics Covered

- 1D Arrays
- Array Traversal
- Linear Search
- Binary Search
- Bubble Sort
- Sorting Colors
- Sum, Average, Minimum and Maximum
- Odd and Even Numbers
- Largest, Smallest and Second Largest
- Reverse Array
- Frequency of Elements
- Running Sum
- Sliding Window
- Two Pointer Technique
- Search Insert Position
- Single Number Problems
- Power of 2, 3 and 4
- LeetCode Array Problems

## LeetCode Problems

Some problems are based on LeetCode, including:

- Container With Most Water
- Even Number of Digits
- Maximum Average Subarray
- Number of Good Pairs
- Running Sum of 1D Array
- Search Insert Position
- Single Number
- Sort Colors

## Language Used

- Java

## Purpose

This repository is created to practice Java arrays,
data structures, algorithms, and problem-solving skills.
